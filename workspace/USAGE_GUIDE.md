## 🎮 CONTROLS

### Main Recognition System
- **Start**: Run the command above
- **Quit**: Press `q` key
- **View**: See real-time FPS, face detection, names with confidence scores

### Learning Mode (Adding New People)
- **Select Person Slot**: Press keys `1` through `9`
- **Capture Face**: Press `SPACE` when face is in green box (good quality)
- **Exit**: Press `ESC` key
- **Goal**: Collect 20-50 high-quality face samples per person
